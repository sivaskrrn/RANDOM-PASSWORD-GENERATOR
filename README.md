##OIBSIP_python_taskno1
 
Objectives

To develop a Python program that generates a random password based on the user's desired length and selected character types (letters, numbers, and symbols).

Steps Performed

1. Imported the `random` and `string` modules.
2. Accepted the password length from the user.
3. Asked the user whether to include letters, numbers, and symbols.
4. Built a character set according to the user's choices.
5. Randomly selected characters from the character set to generate the password.
6. Displayed the generated password to the user.

Tools Used

* **Programming Language:** Python
* **Modules/Libraries:**

  * `random` – for selecting random characters.
  * `string` – for accessing predefined letters, digits, and special symbols.
* **Development Environment:** Any Python IDE (e.g., IDLE, VS Code, PyCharm, or Jupyter Notebook).

Outcome

A Python-based random password generator was successfully created. It generates secure, customizable passwords based on the user's preferences for length and character types, making it useful for creating strong passwords.
